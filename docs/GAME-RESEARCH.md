# Исследование игры (заготовка, Этап 0–1)

Сюда собираем всё найденное по внутренностям `gta-vc.exe` **1.0 US**,
прежде чем оно попадёт в `client/src/game/addresses.h` и `structures.h`.

## Что предстоит найти/подтвердить в первую очередь

- [ ] Точка главного цикла игры (куда ставить хук «каждый кадр»)
- [ ] Создание Direct3D8-устройства (куда ставить хук рендера)
- [ ] Указатель на локального игрока (`CPlayerPed*`), пулы педов/машин игры
- [ ] Функции создания педа и машины, установки позиции/HP/оружия
- [ ] Функции отключения ИИ педа (для «кукол» удалённых игроков)
- [ ] Система времени/погоды (`CClock`, `CWeather`)
- [ ] Обработка урона и стрельбы (`CWeapon::Fire*`) — Этап 5

## Источники

- **reVC** — реверснутые исходники VC от комьюнити (ищем форки на GitHub) — основной справочник;
- **plugin-sdk** (DK22Pac) — заголовки структур/адресов для VC;
- GTAMods Wiki, GTAForums (архивы тредов VC-MP);
- собственная проверка в Ghidra + x32dbg на живом exe (доверяй, но проверяй:
  неверный адрес = краш без стектрейса).
