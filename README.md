# Vice City Multiplayer Client

Мультиплеерный клиент для **GTA: Vice City** в духе SA-MP: лаунчер со списком серверов,
клиентская DLL внутри игры, выделенный сервер со скриптовыми игровыми режимами.

> ⚠️ Проект на этапе проектирования (Этап 0). Играбельного билда пока нет —
> см. [ROADMAP](docs/ROADMAP.md).

## Состав

| Каталог | Что это |
|---|---|
| [`client/`](client/) | DLL, внедряемая в `gta-vc.exe`: хуки игры, сеть, синхронизация, чат |
| [`launcher/`](launcher/) | Лаунчер игрока: сервер-браузер, запуск игры + инжект DLL |
| [`server/`](server/) | Выделенный игровой сервер + Lua-скрипты режимов |
| [`shared/`](shared/) | Общий код клиента и сервера: сетевой протокол, математика |
| [`sdk/`](sdk/) | SDK плагинов сервера и примеры gamemode |
| [`docs/`](docs/) | Документация проекта |

## Требования кратко

- Windows 10/11, Visual Studio 2022 (C++, платформа Win32/x86), CMake 3.25+, vcpkg
- Оригинальная GTA: Vice City с `gta-vc.exe` **1.0 US** (не Definitive Edition)

## Правовая заметка

Репозиторий содержит только наш код. Файлы игры не распространяются:
клиент ставится поверх легально приобретённой копии GTA: Vice City,
как это делают SA-MP / VC-MP / MTA. Неофициальный фанатский проект,
не аффилирован с Rockstar Games и Take-Two Interactive.
