# client/ — клиентская DLL (`vc-client.dll`)

Код, который живёт **внутри процесса `gta-vc.exe`** после инжекта из лаунчера.
Только Windows, только x86 (игра 32-битная).

| Подкаталог | Ответственность |
|---|---|
| `src/core/` | `CClient` — жизненный цикл, конфиг, перехват крашей |
| `src/game/` | Адреса и структуры игры, обёртки `CGame/CPlayerPed`, хуки (`src/game/hooks/`) |
| `src/network/` | Подключение к серверу, отправка/приём синхронизации, интерполяция |
| `src/pools/` | Удалённые игроки, машины, объекты, пикапы: id ⇄ объект в игре |
| `src/render/` | Чат, скорборд, никнеймы — рисуется в хуке Direct3D8 |
| `src/rpc/` | Обработчики команд от сервера |

Статус: каркас (только `dllmain.cpp`-заглушка). Следующий шаг — Этап 1 в [ROADMAP](../docs/ROADMAP.md).
