# server/ — выделенный игровой сервер (`vc-server`)

Консольная программа для владельцев серверов. В отличие от клиента,
собирается и под **Linux** (хостинги) — поэтому никакой привязки к игре и WinAPI здесь быть не должно:
мир игры сервер знает только как данные (координаты, id моделей).

| Подкаталог / файл | Ответственность |
|---|---|
| `src/core/` | `CServer`: старт, `server.cfg`, announce на master-server |
| `src/network/` | ENet host, handshake и проверка версии протокола, query-ответы лаунчеру |
| `src/pools/` | Серверная правда о мире: игроки, машины, объекты + стриминг по радиусу |
| `src/scripting/` | Lua VM и API игровых режимов (`CreateVehicle`, `SendClientMessage`, ...) |
| `config/server.cfg.example` | Пример конфига владельца сервера |

Статус: каркас (печатает версию и завершается).
