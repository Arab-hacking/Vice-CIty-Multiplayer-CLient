# sdk/ — материалы для владельцев серверов и скриптеров

| Путь | Что будет |
|---|---|
| `server-plugin-sdk/include/` | Заголовки C++ API для нативных плагинов сервера (Этап 6+) |
| `examples/gamemodes/` | Примеры игровых режимов на Lua: `freeroam.lua`, `deathmatch.lua` |
| `examples/filterscripts/` | Мелкие дополнения: админка, меню спавна машин и т.д. |

Описание Lua API по мере появления — в `docs/SCRIPTING-API.md`.
