# tools/ — утилиты разработки (не для игроков)

| Утилита | Зачем |
|---|---|
| `bot-client/` | Консольный «фейковый игрок» без игры: подключается к серверу по протоколу, шлёт синхронизацию. Нужен для автотестов сервера и проверки нагрузки (50 ботов = 50 «игроков» без 50 копий GTA). |
| `packet-tester/` | Ручная отправка/просмотр пакетов протокола при отладке сети. |

Обе появятся на Этапе 2 вместе с сетью.
