# masterserver/ — каталог публичных серверов (Этап 7)

Маленький HTTP-сервис (Python/Go, решим позже) на одном VPS:

- `POST /announce` — игровой сервер раз в ~60 сек сообщает: IP, порт, имя, онлайн, режим;
- `GET /servers` — лаунчер получает JSON-список для вкладки «Internet»;
- сервера, не присылавшие announce > 5 минут, выпадают из списка.

Без master-сервера мультиплеер работает по прямым IP и вкладке Favorites —
поэтому компонент сознательно делается последним.
