# tests/

| Каталог | Что тестируем |
|---|---|
| `unit/` | BitStream, сериализацию пакетов, математику — всё из `shared/`, без запуска игры |
| `integration/` | Сценарии «подняли сервер → bot-client подключился → получил спавн» |

Клиентскую DLL автотестами покрыть почти невозможно (нужна живая игра) —
её проверяем вручную по чек-листам этапов из ROADMAP.
